# Лабораторная работа 4 — Операции с файловой системой

## Теоретическая база

### Файловая система Linux: ключевые понятия

| Понятие | Описание |
|---------|---------|
| **inode** | Метаданные файла (права, размер, время, счётчик ссылок). Не содержит имя файла |
| **Жёсткая ссылка** | Дополнительное имя на тот же inode |
| **Символическая ссылка** | Файл-указатель на путь (может указывать на несуществующий файл) |
| **Корзина (Trash)** | Каталог `~/.trash` — временное хранилище «удалённых» файлов |
| **Резервная копия** | Копия данных на случай потери или повреждения оригинала |

### Основные команды работы с файлами

| Команда | Действие |
|---------|---------|
| `mv` | Перемещение / переименование файла или каталога |
| `cp` | Копирование файлов и каталогов |
| `find` | Поиск файлов по условию |
| `stat` | Метаданные файла (размер, время, inode) |
| `readlink -f` | Абсолютный путь, разрешающий все символические ссылки |
| `mkdir -p` | Создать каталог (и промежуточные каталоги, если не существуют) |
| `basename` | Имя файла без пути |
| `dirname` | Путь к каталогу без имени файла |

## Задание 1 — Безопасное удаление в корзину (`rmtrash`)

**Файл:** `task1_rmtrash.sh`

### Алгоритм

1. Создать `~/.trash`, если не существует.
2. Для каждого аргумента: получить абсолютный путь, сформировать уникальное имя в корзине, переместить туда файл, записать лог.

### Разбор кода

```bash
TRASH="$HOME/.trash"
LOG="$TRASH/trash.log"
mkdir -p "$TRASH"
```

`$HOME` — переменная окружения, содержащая домашний каталог пользователя (`/home/имя`).

```bash
abs_path=$(readlink -f "$target")
base=$(basename "$abs_path")
timestamp=$(date "+%Y-%m-%d %H:%M:%S")
```

| Команда | Описание |
|---------|---------|
| `readlink -f` | Возвращает абсолютный канонический путь (раскрывает `..`, `~`, симлинки) |
| `basename <путь>` | Возвращает имя файла без каталога (последний компонент пути) |
| `date "+%Y-%m-%d %H:%M:%S"` | Форматированная метка времени: год-месяц-день часы:минуты:секунды |

### Разрешение конфликтов имён в корзине

```bash
dest="$TRASH/$base"
counter=1
while [ -e "$dest" ]; do
    dest="$TRASH/${base}.${counter}"
    counter=$((counter + 1))
done
```

Если в корзине уже есть файл с таким именем, добавляется числовой суффикс: `.1`, `.2`, и т.д.

| Элемент | Описание |
|---------|---------|
| `[ -e "$dest" ]` | Проверка существования файла или каталога (любого типа) |
| `$((counter + 1))` | Арифметика bash |

### Перемещение и логирование

```bash
mv "$abs_path" "$dest"
echo "$timestamp | $abs_path | $(basename "$dest")" >> "$LOG"
```

`mv` в пределах одной файловой системы не копирует данные — лишь обновляет запись в каталоге (атомарная операция). При перемещении между разными ФС — копирует и удаляет.

Формат лога:
```
2026-05-07 14:30:00 | /home/user/docs/file.txt | file.txt
```

### Проверка существования цели

```bash
if [ ! -e "$target" ]; then
    echo "rmtrash: '$target': нет такого файла или каталога" >&2
    continue
fi
```

| Элемент | Описание |
|---------|---------|
| `[ ! -e ]` | Отрицание условия существования |
| `>&2` | Вывод в stderr (поток ошибок) |
| `continue` | Пропустить текущую итерацию цикла `for` |

## Задание 2 — Восстановление из корзины (`untrash`)

**Файл:** `task2_untrash.sh`

### Два режима работы

**Без аргументов** — интерактивный режим:

```bash
if [ $# -eq 0 ]; then
    ls "$TRASH" | grep -v '^trash\.log$'
    read -rp "Введите имя файла для восстановления: " fname
else
    fname="$1"
fi
```

| Элемент | Описание |
|---------|---------|
| `$#` | Количество аргументов скрипта |
| `ls "$TRASH"` | Список файлов в корзине |
| `grep -v '^trash\.log$'` | Исключить файл лога из вывода (`-v` инвертирует совпадение) |
| `read -rp "..."` | Читать ввод пользователя с подсказкой (`-p` = prompt) |

### Поиск оригинального пути в логе

```bash
orig_path=$(grep -F "| $fname" "$LOG" | tail -1 | cut -d'|' -f2 | xargs)
```

| Команда/флаг | Описание |
|-------------|---------|
| `grep -F` | Поиск фиксированной строки (не regexp) — быстрее и безопаснее |
| `tail -1` | Взять последнюю строку (самую свежую запись о файле) |
| `cut -d'\|' -f2` | Разбить по разделителю `|` и взять 2-е поле (путь) |
| `xargs` | Убрать пробелы в начале и конце строки (trim) |

### Восстановление файла

```bash
if [ -n "$orig_path" ]; then
    dest_dir=$(dirname "$orig_path")
    mkdir -p "$dest_dir"
    mv "$file_in_trash" "$orig_path"
    grep -vF "| $fname" "$LOG" > "${LOG}.tmp" && mv "${LOG}.tmp" "$LOG"
else
    mv "$file_in_trash" "./$fname"
fi
```

| Элемент | Описание |
|---------|---------|
| `[ -n "$var" ]` | Проверка: строка непуста |
| `dirname "$path"` | Возвращает каталог из пути |
| `mkdir -p` | Создаёт каталог вместе со всеми промежуточными |
| `grep -vF "..." "$LOG" > tmp && mv tmp "$LOG"` | Удаление строки из файла: фильтрация во временный файл с заменой оригинала |

## Задание 3 — Резервное копирование (`backup`)

**Файл:** `task3_backup.sh`

### Часть a) — Создание датированного каталога

```bash
DATE=$(date +%Y-%m-%d)
BACKUP_DIR="$HOME/Backup-$DATE"
mkdir -p "$BACKUP_DIR"
```

Имя каталога содержит дату, что позволяет хранить несколько резервных копий с разными датами.

### Часть b) — Копирование и отчёт

```bash
cp -r "$SOURCE/." "$BACKUP_DEST/"
```

| Флаг | Описание |
|------|---------|
| `cp -r` | Рекурсивное копирование (каталог со всем содержимым) |
| `"$SOURCE/."` | Точка после слеша: копировать содержимое каталога, а не сам каталог |

### Формирование отчёта через `find` и `stat`

```bash
find "$SOURCE" -type f | sort | while read -r f; do
    size=$(stat -c '%s' "$f")
    rel="${f#$SOURCE/}"
    printf '%8d  %s\n' "$size" "$rel"
done
```

| Элемент | Описание |
|---------|---------|
| `find <путь> -type f` | Найти только обычные файлы (не каталоги, не симлинки) |
| `sort` | Сортировать найденные пути лексикографически |
| `stat -c '%s'` | Форматированный вывод `stat`: `%s` = размер в байтах |
| `${f#$SOURCE/}` | Параметрическая подстановка: удалить префикс `$SOURCE/` из `$f` |
| `printf '%8d  %s\n'` | Форматированный вывод: число в поле 8 символов, строка |

### Перенаправление группы команд в файл

```bash
{
    echo "Отчёт о резервном копировании — $(date)"
    find "$SOURCE" -type f | ...
} > "$REPORT"
```

`{ ... }` — группировка команд. Весь их stdout перенаправляется в один файл.

### Часть c) — Версионированная копия

```bash
VERSIONED="$HOME/source.$DATE"
cp -r "$SOURCE" "$VERSIONED"
{ ... } >> "$REPORT"
```

`>>` — дозапись в уже существующий отчёт.

## Задание 4 — Восстановление из резервной копии (`upback`)

**Файл:** `task4_upback.sh`

### Логика выбора источника резервной копии

```bash
if [ -d "$DATED_BACKUP" ] && [ -n "$(ls -A "$DATED_BACKUP" 2>/dev/null)" ]; then
    SOURCE="$DATED_BACKUP"
elif [ -d "$FALLBACK_BACKUP" ] && [ -n "$(ls -A "$FALLBACK_BACKUP" 2>/dev/null)" ]; then
    SOURCE="$FALLBACK_BACKUP"
else
    SOURCE=$(find "$HOME" -maxdepth 1 -name 'Backup-*' -type d | sort | tail -1)
fi
```

| Элемент | Описание |
|---------|---------|
| `[ -d "$path" ]` | Проверка: путь является каталогом |
| `ls -A` | Список файлов включая скрытые, но без `.` и `..` |
| `-maxdepth 1` | Искать только в указанном каталоге, не рекурсивно |
| `-name 'Backup-*'` | Фильтр по шаблону имени |
| `sort \| tail -1` | Самый «последний» по лексикографической сортировке = самая свежая дата |

### Восстановление

```bash
mkdir -p "$RESTORE_DIR"
cp -r "$SOURCE/." "$RESTORE_DIR/"
```

### Вывод восстановленных файлов

```bash
find "$RESTORE_DIR" -type f | sort | while read -r f; do
    echo "  ${f#$RESTORE_DIR/}"
done
```

`${f#$RESTORE_DIR/}` — удаляет префикс пути, оставляя только относительный путь файла.

## Сводная таблица флагов команд

### `find`

| Флаг | Описание |
|------|---------|
| `-type f` | Только обычные файлы |
| `-type d` | Только каталоги |
| `-name 'шаблон'` | Фильтр по имени (glob) |
| `-maxdepth N` | Глубина рекурсии |
| `-exec cmd {} \;` | Выполнить команду для каждого найденного файла |

### `stat`

| Формат | Описание |
|--------|---------|
| `%s` | Размер файла в байтах |
| `%n` | Имя файла |
| `%y` | Время последнего изменения (mtime) |
| `%a` | Права доступа в восьмеричном виде |
| `%U` | Имя владельца |

### `cp`

| Флаг | Описание |
|------|---------|
| `-r` | Рекурсивное копирование |
| `-p` | Сохранить права, время модификации |
| `-u` | Копировать только если источник новее цели |
| `-v` | Подробный вывод |

### `mv`

| Флаг | Описание |
|------|---------|
| `-f` | Принудительно (без запроса при перезаписи) |
| `-n` | Не перезаписывать существующие файлы |
| `-v` | Подробный вывод |

## Параметрическая подстановка (Parameter Expansion)

| Синтаксис | Описание | Пример |
|-----------|---------|--------|
| `${var#prefix}` | Удалить кратчайший префикс | `${f#$SOURCE/}` |
| `${var##prefix}` | Удалить длиннейший префикс | `${pid##*/}` |
| `${var%suffix}` | Удалить кратчайший суффикс | `${file%.*}` |
| `${var%%suffix}` | Удалить длиннейший суффикс | |
| `${var:-default}` | Значение по умолчанию если var пуста | `${1:-10}` |
| `${#var}` | Длина строки | |
